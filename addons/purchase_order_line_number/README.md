# Purchase Order Line Number

Fügt eine fortlaufende Positionsnummer (`number`) zu den Bestellpositionen
(`purchase.order.line`) hinzu und zeigt sie im Bestellformular an.

Odoo-18-Migration des gleichnamigen Odoo-11-Moduls (Schwester von
`sale_order_line_number` und `account_invoice_line_number`).
